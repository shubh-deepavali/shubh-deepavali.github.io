# दिवाळीच्या शुभेच्छा

An interactive Diwali greeting: light the diya with a matchstick, then fireworks, sanai and dholak.

## Put it online with GitHub Pages

1. On github.com, create a new **public** repository named `diwali`.
2. Click **Add file → Upload files** and drop in `index.html`, `og.png` and this README. Commit.
3. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. After a minute or two the page is live at `https://ashishapte2810.github.io/diwali/`.

## Personalised links

Light the diya, tap **नावे बदला**, type the names (Devanagari or English) and use **Copy link**, **Share** or **Send on WhatsApp**. Anyone who receives the page can do the same with their own names.

## Music

The background music is built into `index.html`, so the page works as a single file. Only use audio you have the rights to share publicly.
